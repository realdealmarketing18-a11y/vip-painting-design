# Soul Character — Fabian (On-Screen Founder)

Fabian is the recurring on-screen face of VIP across every episode. This sub-skill produces **Stream 2** (Fabian B-roll only — no house reference in these shots). Use the installed `higgsfield-soul` sub-skill for the mechanics.

## THE ONE-CHARACTER-SLOT RULE (critical)

Higgsfield has a single character slot, and house photos occupy the reference-image slot. **You cannot put Fabian + house + repaint prompt in one pass.** Therefore:

- Generate Fabian shots **separately** from house renders.
- Composite Fabian over/between the house renders in CapCut.
- Never write a prompt like "Fabian standing in front of the transformed house" expecting one Higgsfield output — it will fail or drop one element. Instead: render the house (Stream 1), render Fabian against a clean/contextual background (Stream 2), layer in edit.

## SOUL TRAINING (one-time, reused forever)

- Train a Soul character of Fabian from **20+ photos**, **white polo preferred** (brand wardrobe). Front, 3/4, and profile angles; consistent grooming; neutral and warm expressions.
- Soul ID requires a human face (this is why the house can't be a Soul character).
- Requires the Soul ID subscription tier ($15/mo minimum) to unlock multiple character references.
- Save the returned reference/character ID. Reuse it across all episodes — no retraining unless wardrobe/look changes.

## FABIAN B-ROLL SHOT LIST (per episode)

Generate these as separate Soul-character shots, then composite at the mapped beats:

1. **Presenting the visualization** (Discovery, S4) — Fabian in white polo, holding/gesturing at a tablet showing color options, warm confident expression, clean premium interior or porch background. Golden-hour key light.
2. **Reviewing swatches** (Step 1–2, S5–S6) — Fabian considering SW swatch cards / palette options, consultative posture.
3. **Direct-to-camera invitation** (optional CTA, S8) — Fabian addressing the viewer, warm, assured, navy/gold-graded background.

Keep wardrobe (white polo) and grade (navy + gold sensibility) consistent so Fabian reads as the same person across every cut and every episode.

## DOUGLAS & SHERI (NOT Soul characters)

The homeowners appear via their **real portrait photo and any real footage** — not generated characters. The only exception is the 3-panel static editorial ad (GPT Image 2), where a generated couple matching their description is acceptable for that single asset.

## BRAND + SAFETY

- White polo, premium, approachable-expert energy.
- Never reference "AI" — Fabian is presenting "VIP Premier's Custom Color Scheme Visualization."
- Navy/gold grade; logo on white pill if it appears on a dark background.

## REUSE

The Fabian Soul character is built once and reused across all 15 communities. Only regenerate B-roll if the setting or wardrobe changes for a specific episode.
