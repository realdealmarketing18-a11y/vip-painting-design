# Marketing Studio — TV Spot (Social Cut)

The 4–5 min YouTube episode is the hero. This sub-skill produces the **short narrative cuts** that actually run as paid ads. Two paths:

## PATH A — Recut from episode assets (preferred, free)

Pull the strongest beats from the finished episode into shorter edits in CapCut:

- **90-second Reel/FB ad:** Hook (gold split) → one line of struggle → Custom Color Scheme Visualization tease → gold-wipe reveal → CTA. Keep Fabian's hook VO + the reveal.
- **15-second silent website loop:** Render A BEFORE → gold wipe → Render K hero, Ken Burns, text-only ("SEE IT. LOVE IT. PAINT IT." + phone). No VO; designed for autoplay-muted.
- **30-second story ad:** Hook → reveal → CTA. Tightest possible transformation proof.

Always lead with the result (HGTV cold-open logic) — the reveal is the scroll-stopper.

## PATH B — Higgsfield Marketing Studio narrative mode

For a fast standalone spot without full episode assembly, use the installed `higgsfield` library's Marketing Studio / TV-spot path:

- Feed the chosen-palette hero render (K) + the transformation framing.
- Request a cinematic narrative "TV Spot" treatment, not generic UGC, for the luxury positioning.
- If available, run the result through the Virality Predictor (hook strength / retention) before publishing.

## BRAND RULES (same as master)

- Never "AI" — "Custom Color Scheme Visualization."
- Navy #1a1f4e + gold #FFB200 grade. Logo on white pill over dark.
- On-screen text uses "complimentary"; spoken VO may use the approved "FREE."
- Taglines: "See It. Love It. Paint It." / "Visualize It. See It. Paint It."
- CTA bar: navy bg, gold border, "(909) 312-5400 · BOOK YOUR COMPLIMENTARY VISUALIZATION."

## DISTRIBUTION (3-step funnel)

Episode → "which color would you choose?" poll/engagement ad → retarget CTA ad to engagers. The short cuts feed steps 2 and 3.

## REUSE

Cut templates (90s / 30s / 15s) are fixed structures. Swap the episode's renders and homeowner name; the beat order and timing hold across communities.
